# shatalov-alex/tap

Homebrew formulae for [kcsecret](https://github.com/shatalov-alex/kcsecret): developer secrets in a
Touch ID keychain, loaded per project by direnv.

```zsh
brew install shatalov-alex/tap/kcsecret
```

Update with `brew upgrade kcsecret`. The formula installs the signed release binary unchanged, so the
keychain keeps trusting kcsecret across upgrades.
